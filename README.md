# CampusAI

AI-powered college academic platform for students, faculty, and administrators.

## Planned modules
- Student and faculty authentication
- Assignment creation and submission
- Secure cloud file storage
- Faculty submission dashboard
- Subject-specific AI assistant using RAG
- Notifications and academic analytics

## Architecture
React + Tailwind CSS → FastAPI → PostgreSQL / Object Storage → AI/RAG services

## Development status
Phase 1: Foundation and project architecture.
